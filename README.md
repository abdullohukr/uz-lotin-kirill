# Lotin ⇄ Kirill — надстройка Word для Mac и Windows

Переводит узбекский текст между латиницей и кириллицей прямо в Word.

* **Кавычки « » “ ” " ' не трогаются никогда** — в движке нет ни одной строки, которая их меняет
  (проверяется тестами, включая вложенные `«Нега «қадр» синдирдинг»`).
* Меняются только буквы. Форматирование, выделение цветом, шрифты, сноски, картинки остаются.
* Работает с выделенным текстом, а если ничего не выделено — со всем документом
  (основной текст, сноски, колонтитулы).
* Один и тот же код работает в Word для Mac, Windows и Word Online.
* Свой словарь исключений (Ҳирақл, Расулуллоҳ…) и список слов, которые не надо переводить.

## Что внутри

| Папка / файл | Что это |
|---|---|
| `src/engine.js` | Движок транслитерации (правила) |
| `data/exceptions.json` | Исключения (≈900 словоформ + ≈880 основ) — итоговый файл, собирается генератором |
| `data/savodxon_pairs.tsv` | Список Savodxon (`lotin<TAB>кирилл`, `[ь]` — ь только в конце слова) |
| `data/manual.js` | Исключения, добавленные вручную (месяцы, ижмоъ, асҳоб, цирк, цех…) |
| `addin/` | Сама надстройка: панель, кнопки на ленте, манифест |
| `tools/build_exceptions.js` | Генератор исключений из корпуса |
| `tools/build.sh` | Сборка надстройки в `docs/` (GitHub Pages) |
| `vba/UzLotinKirill.bas` | Офлайн-макрос для Word (генерируется `tools/build_vba.js`) |
| `test/run_tests.js` | Тесты |

### Правила

* е → ye в начале слова и после гласной (ер → yer, поезд → poyezd); ye → е обратно.
* e → э в начале слова и после гласной (ekran → экран, poema → поэма), но фамилии
  Abdullaev/Boboev → Абдуллаев/Бобоев.
* ц → ts после гласной, иначе s; -tsiya / -tsion → -ция / -цион.
* ts в узбекских словах остаётся тс: ketsa → кетса, baxtsizlik → бахтсизлик.
* сҳ ↔ s’h (Исҳоқ ↔ Is’hoq), а также ashob/Ishoq/mushaf без апострофа → асҳоб/Исҳоқ/мусҳаф.
* yo‘ → йў (yo‘l → йўл), остальные yo/yu/ya → ё/ю/я.
* o‘ в конце слова → ў (obro‘ → обрў); ijmo‘/istisno‘/qino‘ → ижмоъ/истисноъ/қиноъ.
* mo‘jiza, mo‘tabar, mo‘tadil → мўъжиза, мўътабар, мўътадил.
* ъ ↔ ’ (Қуръон ↔ Qur’on), объект → obyekt.
* Ссылки (https://…, www.…) и e-mail не трогаются.
* Римские цифры (XX, XIV) не трогаются.
* **Иностранные слова и названия остаются латиницей** (галочка в панели, в макросе `KEEP_FOREIGN`):
  * явно иностранные слова — буквы w, c, заглавная внутри слова (YouTube, iPhone, CadenzaX),
    сочетания, которых нет в узбекском (ph, ee, gh, ck, -ple/-gle, согласная + y в конце);
  * короткие (до 4 слов) названия в кавычках с иностранным словом: «Gold Kvest», «Seven Daymond»,
    «CadenzaX music», «VIP». Длинные цитаты и одиночные слова в кавычках («Nun», «Hud») переводятся;
  * названия из заглавных слов рядом с явно иностранным словом: Apple Music;
  * всегда латиницей: VIP, SMS, PDF, USB, online… (`data/acronyms.json`; короткие — только заглавными);
  * **бренды** (`data/brands.txt`, ≈1600 названий): платёжные системы и банки (Visa, Mastercard,
    American Express, PayPal), авиакомпании (Turkish Airlines, Emirates, Uzbekistan Airways), марки и
    модели машин (Toyota Camry, Chevrolet Malibu, BYD), техника и приложения (Samsung, Telegram,
    TikTok), одежда, косметика, еда, отели, СМИ. Название сохраняется, только если написано
    с заглавной буквы. В список не входят слова, у которых есть узбекское значение (Humo, Uzum,
    Ravon, Mars, Astana, Rio, Panda, Kakao…) и бренды русского происхождения (Lada, Yandex, Gazprom) —
    они переводятся как обычно: *Humo qushi → Ҳумо қуши*, *Mars sayyorasi → Марс сайёраси*.
    Список можно дополнять: одна строка — одно название, затем `python3 tools/build_brands.py`;
  * слова с буквами ü, é, ö… (Ülker, Müller, Citroën) остаются латиницей целиком.
* Одна буква с точкой — это инициал (M. Yusuf → М. Юсуф), без точки — римская цифра (V asr).
  Английский список (`data/foreign.json`) — частотный список FrequencyWords (MIT), из которого убраны
  слова, которые узбекские кириллические тексты пишут кириллицей (спорт, интернет, ҳам, мен).

### Откуда исключения

Кириллица → латиница почти всегда идёт строго по правилам. Поэтому генератор прогоняет каждое
кириллическое слово из корпуса туда и обратно. Если слово не возвращается в исходном виде, а его
латинское написание действительно встречается в латинских текстах, слово становится исключением.
Там, где весь корпус согласен, генератор обобщает слово до основы, чтобы покрыть и новые суффиксы.

Корпус: Leipzig Corpora Collection, узбекский (community 2017 + Wikipedia 2021, лицензия CC BY).
Используются только предложения, написанные «правильной» кириллицей (с ў қ ғ ҳ).
Дополнительно взяты списки UzTransliterator (лицензия MIT) и список Savodxon (около 1300 основ,
в основном научные термины). Каждая основа Savodxon проверяется по корпусу; ~70 противоречивых
или слишком коротких записей (sia, tsit, tush…) отброшены.

Точность на корпусе (≈4 млн словоупотреблений, кириллица → латиница → кириллица): **≈99,7 %**.
Почти все оставшиеся расхождения — разные допустимые варианты написания (январь/январ).

## Два варианта

| | Надстройка (онлайн) | Макрос (офлайн) |
|---|---|---|
| Где работает | Word для Mac, Windows, Word Online | Word для Mac и Windows |
| Интернет | нужен при запуске Word | не нужен |
| Обновления | приходят сами | заменить файл `.bas` |
| Кнопки | своя вкладка **Lotin-Kirill** | добавляются вручную (один раз) |
| Свой словарь | в панели (**Panel**) | документ `UzLotinKirill-lugat.docx` (макрос **UzLugat**) |

Правила и словарь у обоих вариантов одинаковые: макрос генерируется из того же движка.
Можно поставить оба.

## Вариант 1. Надстройка (онлайн)

Надстройка размещена на GitHub Pages: https://abdullohukr.github.io/uz-lotin-kirill/
Для установки нужен только файл [`manifest.xml`](manifest.xml)
(на GitHub: открыть файл → кнопка **Download raw file**).

### Mac

1. Полностью закройте Word (⌘Q).
2. В Finder нажмите **⇧⌘G** и вставьте путь:
   `~/Library/Containers/com.microsoft.Word/Data/Documents/wef/`
   Если папки `wef` нет — создайте её.
3. Скопируйте туда `manifest.xml`.
4. Откройте Word → **Вставка → Надстройки → Мои надстройки** → раздел
   «Надстройки разработчика» → **Lotin ⇄ Kirill**.
5. На ленте появится вкладка **Lotin-Kirill** с кнопками **Kirillga**, **Lotinga**, **Panel**.

### Windows

Microsoft 365 и Word 2021+: **Главная → Надстройки → Дополнительные надстройки → Мои надстройки →
Отправить мою надстройку** → выбрать `manifest.xml`.

Word 2016/2019 (через общую папку):
1. Создайте папку, например `C:\Addins`, положите в неё `manifest.xml`.
2. ПКМ по папке → **Свойства → Доступ → Общий доступ** → скопируйте сетевой путь
   (вида `\\ИМЯ-ПК\Addins`).
3. Word → **Файл → Параметры → Центр управления безопасностью → Параметры центра управления
   безопасностью → Доверенные каталоги надстроек** → вставьте путь → **Добавить каталог** →
   галочка **Показать в меню** → OK → перезапустите Word.
4. **Вставка → Мои надстройки → Общая папка → Lotin ⇄ Kirill**.

### Как пользоваться

* Выделите текст и нажмите **Kirillga** или **Lotinga**. Если ничего не выделено — переводится
  весь документ (вместе со сносками и колонтитулами).
* **Panel** открывает панель: выбор области, окно для быстрой проверки, свой словарь
  (`lotin = кирилл`, по одному на строку), список слов, которые не надо переводить, и вид
  апострофа в латинице (‘ ’ или официальные ʻ ʼ, или простой ').
* Отменить: ⌘Z / Ctrl+Z. Большие книги лучше перед переводом сохранить.

## Вариант 2. Макрос (офлайн)

Файл: [`vba/UzLotinKirill.bas`](vba/UzLotinKirill.bas) (на GitHub: **Download raw file**).
Работает без интернета и без установки чего-либо — только Word.

### Установка (Mac и Windows одинаково)

1. Word → **Сервис → Макрос → Редактор Visual Basic**
   (Mac: меню **Сервис**; Windows: **Alt+F11**).
2. Слева выберите проект **Normal** (на Windows — `Normal`, на Mac — `Normal.dotm`).
3. **File → Import File…** → выберите `UzLotinKirill.bas`. Появится модуль `UzLotinKirill`.
4. Закройте редактор. При выходе из Word согласитесь сохранить `Normal`.
5. Проверка: **Сервис → Макрос → Макросы → UzSelfTest → Выполнить**.
   Должно появиться «Hammasi to'g'ri».

### Кнопки на ленте

* **Mac:** Word → **Настройки → Лента и панель инструментов** → слева «Выбрать команды из:
  **Макросы**» → справа создайте новую вкладку/группу → перетащите `UzKirillga` и `UzLotinga`
  (можно переименовать в «Kirillga» / «Lotinga» и выбрать значок).
* **Windows:** **Файл → Параметры → Настроить ленту** → «Выбрать команды: **Макросы**» →
  **Создать вкладку** → добавьте `Normal.UzLotinKirill.UzKirillga` и `...UzLotinga` →
  **Переименовать**.

### Макросы

| Макрос | Что делает |
|---|---|
| `UzKirillga` | выделенное (или весь документ, включая сноски, колонтитулы, надписи) → кириллица |
| `UzLotinga` | выделенное (или весь документ) → латиница |
| `UzLugat` | открывает свой словарь `UzLotinKirill-lugat.docx` (лежит рядом с Normal.dotm). Строки `lotin = кирилл`; одно слово в строке — не переводить; `#` — комментарий. Изменения учитываются сразу |
| `UzSelfTest` | проверяет, что модуль работает правильно (≈1260 проверок) |

Вид апострофа в латинице меняется в начале модуля: `Private Const APOS_STYLE As Long = 1`
(1 — ‘ ’, 2 — ʻ ʼ официальные, 3 — простой ').

Отмена: на Windows весь перевод отменяется одним Ctrl+Z; на Mac — по шагам, поэтому перед
переводом большого документа его лучше сохранить.

## Обновление словаря

```bash
# пересобрать исключения из корпуса (файлы cyr.tsv / lat.tsv: "слово<TAB>частота")
jsc=/System/Library/Frameworks/JavaScriptCore.framework/Versions/Current/Helpers/jsc
$jsc tools/build_exceptions.js -- cyr.tsv lat.tsv > data/exceptions.json
$jsc test/run_tests.js
tools/build.sh https://abdullohukr.github.io/uz-lotin-kirill   # обновит docs/ (надстройка)
$jsc tools/build_vba.js > vba/UzLotinKirill.bas                  # обновит офлайн-макрос
git add -A && git commit -m "..." && git push
```

Свои слова удобнее добавлять прямо в панели (**Panel → Mening lug‘atim**) — по одному на строку
в виде `lotin = кирилл`. Они хранятся на этом компьютере.
